# Agent 工程经验库

本目录只保存已验证、可复用且经过脱敏的工程结论，不保存聊天记录、完整日志、密钥、个人信息或客户数据。

## 使用原则

- 在排障、构建、部署、依赖、配置、性能或稳定性任务开始时，先检索相关经验。
- 仅在任务完成并验证后沉淀经验。
- 写入前检查事实、置信度、重复内容和敏感信息。
- 自动保存关闭时，必须取得用户对当前预览的明确保存授权。
